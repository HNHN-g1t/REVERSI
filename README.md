# オセロ（リバーシ）— 2人対戦

1台の画面で2人が交互に打つ、ローカル対戦のオセロです。
React + TypeScript + Vite で作られていて、サーバーは不要です。

## できること

- 8×8 の標準ルール（黒が先手）
- 置ける場所を盤面にドット表示（オン/オフ切り替え可）
- 石が裏返るときの回転アニメーション
- 打てる手がない側は自動でパス。状況はメッセージで表示
- 両者とも打てなくなったら終局、石数で勝敗を判定
- 1手戻す / 最初から
- 直前の手をハイライト、棋譜表記（a1〜h8）を表示
- キーボード操作：`U` 1手戻す、`R` 最初から、`H` ヒント切り替え

## 動かす

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + 本番ビルド（dist/）
npm run preview  # ビルド結果を確認
npm test         # ロジックのテスト
```

## 構成

| ファイル | 役割 |
|---|---|
| `src/reversi.ts` | 盤面ロジック。反転計算・合法手・終局判定。UI に依存しない純粋関数 |
| `src/reversi.test.ts` | 上記のテスト（vitest） |
| `src/App.tsx` | 画面。手番・スコア・履歴（1手戻す）の状態を持つ |
| `src/index.css` | スタイル一式 |

ロジックを `src/reversi.ts` に閉じ込めてあるので、
あとから CPU 対戦を足すときはここに評価関数と探索を書き足すだけで済みます。

## デプロイ

Vite の静的サイトなので、Vercel なら設定なしでそのまま公開できます
（Framework Preset: Vite / Build Command: `npm run build` / Output: `dist`）。
