# REVERSI — リバーシ

CPU 対戦と、1台の画面を2人で囲む対面対戦ができるリバーシです。
React + TypeScript + Vite で作られていて、サーバーは不要です。

公開先: Vercel（`main` に push すると自動でデプロイ）

## 遊び方

タイトルで **START** → モードを選ぶ。

| モード | 内容 |
|---|---|
| **VS CPU** | よわい / ふつう / つよい の3段階。あなたが黒（先手） |
| **ふたりで対戦** | 画面を机に置き、向かい合って遊ぶ。上側（白）の表示は上下反転して白の人に向く |

### 画面の四隅

| 位置 | ボタン | 働き |
|---|---|---|
| 左上 | ☰ | メニュー（最初から / 盤面のデザイン / 石のデザイン / タイトルへ） |
| 左下 | 👁️ | 置ける場所の表示・非表示 |
| 右下 | ↩️ | 1手戻す（CPU 戦では CPU の手もまとめて戻し、自分の番に戻る） |
| 右上 | 🏁 | 終局後、結果画面を閉じたときだけ現れる。結果をもう一度見る |

キーボード: `U` 1手戻す / `H` 置ける場所の表示切り替え / `Esc` メニュー

### コインとスキン

対局を最後まで打つとコインがもらえ、メニューからスキンと交換できます。

| 結果 | よわい | ふつう | つよい | ふたりで対戦 |
|---|---|---|---|---|
| 勝ち | 10 | 20 | 40 | 10（勝敗に関係なく） |
| 引き分け | 5 | 10 | 20 | |
| 負け | 3 | 3 | 3 | |

- 1局につき受け取れるのは1回だけ。↩️ で戻して打ち直しても増えません
- 購入は誤タップ防止のため2回タップで確定。買ったスキンはそのまま装備されます
- コインと所持スキンはブラウザ（端末）ごとに保存されます

| 種類 | スキン | 価格 |
|---|---|---|
| 盤面 | クラシック グリーン | 最初から所持 |
| 盤面 | 石板グレー | 60 |
| 石 | クラシック 白黒 | 最初から所持 |
| 石 | 水晶（透明水晶 × 黒水晶） | 100 |

価格は `src/skins.ts` の `price` で変えられます（0 にすると最初から所持）。

## スキンを PNG に差し替える

いまのスキンは CSS で描いていますが、PNG を置いてパスを書けば画像に切り替わります。

**1. 画像を置く**

```
public/skins/
├── boards/<スキンID>/square.png   1マスぶんのタイル（正方形・推奨 128×128）
├── boards/<スキンID>/board.png    盤全体（正方形・推奨 1024×1024、マス目の線も描く）
├── stones/<スキンID>/black.png    黒石（背景透過・正方形・推奨 256×256）
└── stones/<スキンID>/white.png    白石（同上）
```

盤は `square.png`（マスを敷き詰める）と `board.png`（1枚絵）のどちらか片方で十分です。

**2. `src/skins.ts` に `images` を書き足す**

```ts
{
  id: 'crystal',
  name: '水晶（透明 × 黒）',
  price: 100,
  images: {
    black: skinAsset('stones/crystal/black.png'),
    white: skinAsset('stones/crystal/white.png'),
  },
},
```

書いたものだけが画像になり、書いていないものは CSS のまま残ります。
石は裏返りアニメーションもそのまま効きます。

**新しいスキンを増やす**ときは、`BOARD_SKINS` / `STONE_SKINS` に同じ形で1件足すだけです。
ショップ・購入・保存は自動で対応します。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # テスト
npm run build    # 型チェック + 本番ビルド（dist/）
```

## 構成

| ファイル | 役割 |
|---|---|
| `src/reversi.ts` | 盤面ロジック（反転・合法手・パス/終局判定） |
| `src/ai.ts` | CPU の思考。よわい=ランダム / ふつう=2手読み+ゆらぎ / つよい=5手読み・残り12マスで読み切り |
| `src/skins.ts` | スキンのカタログ（色・価格・PNG のパス） |
| `src/progress.ts` | コイン・所持スキンの保存、購入と報酬の計算 |
| `src/components/TitleScreen.tsx` | タイトルとモード選択 |
| `src/components/GameScreen.tsx` | 対局画面・結果表示 |
| `src/components/Menu.tsx` | メニューとスキンショップ |
| `src/components/Board.tsx` / `Stone.tsx` | 盤と石の描画（CSS / PNG の切り替え） |
| `src/*.test.ts` | テスト（vitest） |
